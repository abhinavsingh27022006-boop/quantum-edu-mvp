# 7. The Quantum NOT (Pauli-X)

Sometimes we don't want a spinning coin. Sometimes we just want to flip the coin over completely.

If a qubit is at 0, and we want it to be a 1, we use the **Pauli-X Gate** (or **X Gate**). This is the quantum equivalent of the classical NOT gate. It flips the bit!

Try it in the simulator below.
1. Click **+ Add Pauli-X**. Watch the state flip to 100% `10` (the 1 state for Q0).
2. What happens if you add an **H Gate** *after* the **X Gate**? Does it still split 50/50? Try it!
