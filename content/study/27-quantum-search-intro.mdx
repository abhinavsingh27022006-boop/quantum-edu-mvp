# 27. Quantum Search Intro

Imagine I give you a phonebook, and I ask you to find the phone number for "Alice". Since the book is sorted alphabetically, you can find it very quickly!

Now, imagine I give you a phone number, and ask you to find the *name* attached to it. The book is not sorted by number. Classically, you have no choice but to start at page 1 and read every single entry until you find a match. If the book has 1 million entries, it will take you, on average, 500,000 tries.

This is the problem of searching unsorted data.

In the late 1990s, Lov Grover discovered that a quantum computer can find the correct entry in an unsorted database using dramatically fewer steps. For 1 million entries, a quantum computer only needs 1,000 tries! 

How? Using interference.
