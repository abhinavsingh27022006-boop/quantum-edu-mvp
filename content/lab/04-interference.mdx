# 4. The Reversing Coin (Interference)

In the classic world, if you flip a coin twice, it's still random. In the quantum world, randomness is completely reversible!

When you put a qubit into superposition with an **H Gate**, you split the probability 50/50. But if you apply a second **H Gate** immediately after it, the wave patterns interfere with each other and perfectly cancel out the randomness.

### Your Task
1. Drag an **H Gate** onto **Q0** and run the simulation. Notice it's 50/50.
2. Now, drag a second **H Gate** onto **Q0** right next to it.
3. Run the simulation again. You'll see the state returns to 100% `00`!
